# History photos for the launch video

Real photos used on the pages of the history book in `video/`. Each one keeps its licence and credit.

| File | What it shows | Source and licence |
|---|---|---|
| `so101_follower_therobotstudio.jpg` | SO-101 follower arm (LeRobot edition) | [TheRobotStudio/SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100) `media/SO101_Follower.webp`, Apache-2.0, resized |
| `so100_leader_follower_therobotstudio.jpg` | SO-100 leader and follower arms | [TheRobotStudio/SO-ARM100](https://github.com/TheRobotStudio/SO-ARM100) `media/Leader_And_Follower_SO100.jpg`, Apache-2.0, resized |

The 1961-2023 pages use line-art illustrations: real photos of Unimate, the Stanford Arm, PUMA, Baxter, ALOHA
and RT-2 were not reachable from the build environment with a clear licence. To use a photo, add it here, then
set that page's `photo` in `video/config.json` to its file name. Record its source and licence in this table.
